# PocketTrack

PocketTrack is a lightweight personal expense tracker for recording, categorising, filtering, and monitoring everyday spending.

## Features

- Add expenses with description, amount, category, and date
- View recent expense history
- Filter expenses by category
- Delete individual expenses
- Persist data using browser localStorage
- Calculate total spending automatically
- Responsive layout for desktop, tablet, and mobile
- Form validation and accessible interaction states

## Git Workflow

Development for PocketTrack follows an issue-driven Git workflow:

- Every development task is tracked using a GitHub issue
- Issues are grouped into development milestones
- Work is isolated on issue-linked branches
- Commits follow the Conventional Commits specification
- Changes are reviewed and merged into `main` through pull requests
- Direct development on `main` is prevented through branch protection
- Merge conflicts are deliberately demonstrated and resolved as part of the project workflow
